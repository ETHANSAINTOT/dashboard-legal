Epitech Dashboard

Epitech Dashboard is a free, non-commercial student project developed at Epitech. Users create an account, then build their own dashboard out of widgets, each refreshed automatically.

The widgets

  • Clock: the live time in any city, with its time zone.
  • Weather and Forecast: the current weather and the next days for a city, with data from Open-Meteo.
  • News: the latest articles of an RSS or Atom feed.
  • Translate: a translator between 11 languages, run on the project's own server.
  • Gmail: the latest emails of a Google account (see below).

Gmail widget

The Gmail widget displays, in read-only mode, the latest emails from the user's inbox: sender, subject, snippet, date, and read/unread status. Clicking an email or "Open Gmail" opens it in Gmail itself. The application never sends, modifies or deletes an email.
